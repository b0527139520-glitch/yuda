# עיצוב "Candy Pop" — מפרט מלא לדף סיפורים עברי

שם הסגנון (כתוב בפועל בקוד ה-CSS): **Candy Pop**.
זהו עיצוב ייעודי לדף אינטרנט יחיד (single-file HTML) המציג **אוסף גדול של סיפורים** בעברית, עם ניווט, תוכן עניינים היררכי וחיפוש טקסט מלא. הוא שונה מהסקיל `torah-html-article-v2` (שמיועד למאמר/ספר בודד עם הקראה קולית ופלטה סגולה-כחולה רצינית) — Candy Pop מיועד לילדים, צבעוני, "מתקתק", ומותאם לספריית סיפורים גדולה עם חיפוש.

כדי לבקש את הסגנון הזה מחדש, אפשר פשוט לכתוב: **"תבנה לי דף בסגנון Candy Pop"** ולצרף מפרט זה, או להפנות לקובץ HTML קיים שנבנה בו.

---

## 1. מבנה הקובץ

קובץ **HTML יחיד ועצמאי** (`<!DOCTYPE html>`, `lang="he" dir="rtl"`), עם:
- `<style>` inline בראש הקובץ — בלי CSS חיצוני מלבד Google Fonts.
- `<script>` inline בתחתית הקובץ — בלי תלות בספריות JS חיצוניות (וניל JS טהור).
- מערך JSON יחיד בשם `searchData` שמכיל **את כל הסיפורים** (למנוע החיפוש), בנפרד מה-HTML המוצג בפועל.

## 2. פלטת צבעים (CSS variables)

```css
:root {
  --pink:   #ff6b9d;
  --blue:   #4ec9f0;
  --yellow: #ffd93d;
  --red:    #ff4757;
  --green:  #7bed9f;
  --purple: #a29bfe;
  --white:  #ffffff;
  --dark:   #2d1b69;
  --shadow: 0 8px 32px rgba(174,0,255,.18);
}
```
רקע הדף: גרדיאנט פסטלי רך `linear-gradient(135deg, #ffe0f7 0%, #e0f4ff 30%, #fff8cc 60%, #ffe0e3 100%)`.
כל פרק/דמות (chapter) מקבל צבע משלו מתוך הפלטה (למשל ורוד, כחול, צהוב, אדום...) שחוזר גם בבועת התוכן עניינים וגם בכותרת הפרק בגוף.

## 3. טיפוגרפיה

- **גוף הטקסט:** `Heebo` (משקלים 300/400/700/900), מ-Google Fonts.
- **כותרות דקורטיביות** (Hero, כותרות פרקים): `Fredoka One` — פונט עגול, ילדותי, עם צל טקסט כפול (`text-shadow: 3px 3px 0 ..., 6px 6px 0 ...`) ליצירת אפקט "בועה".
- כיוון: `direction: rtl` בכל הדף.

## 4. מבנה העמוד (Layout)

### 4.1 Hero Header
- גרדיאנט אלכסוני רב-צבעוני (`pink → purple → blue → yellow`).
- טקסטורת נקודות SVG שקופה ברקע (`::before` עם `background-image` מסוג `data:image/svg+xml`).
- כותרת ראשית עם אימוג'י משני הצדדים (למשל `🍭 סיפורי גדולי ישראל 🍭`).
- כותרת משנה.
- שורת "בועות סטטיסטיקה" (`stat-bubble`) — כמות סיפורים, כמות חכמים וכו', בעיצוב glassmorphism (`backdrop-filter: blur(10px)`, רקע חצי-שקוף, מסגרת לבנה).

### 4.2 Layout כללי — `flex` דו-טורי
- `display: flex` בין `sidebar` קבועה ל-`main` גמיש.
- `max-width: 1400px`, ממורכז.

### 4.3 Sidebar (תוכן עניינים + חיפוש) — עמודה ימנית קבועה (300px, `sticky`)
- רקע לבן חצי-שקוף עם `backdrop-filter: blur(20px)`.
- קופסת חיפוש עגולה (`border-radius: 50px`) עם אייקון 🔍, שמחפשת בזמן אמת בתוך `searchData` (כותרת + גוף).
- תוצאות חיפוש: קופסה נפתחת מתחת לתיבה, כל תוצאה מציגה כותרת עם הדגשת מילת החיפוש (`<mark>`, צבע צהוב) וקטע טקסט (snippet) עם הקשר.
- **תוכן עניינים היררכי מתקפל (accordion):** כל "פרק" (למשל חכם/דמות) הוא קופסה עם מסגרת בצבע ייחודי, כותרת לחיצה שפותחת/סוגרת רשימת סיפורים מתחתיה (`max-height` transition), עם חץ שמסתובב 180° במצב פתוח, ותגית עגולה שמציגה כמות סיפורים בפרק.

### 4.4 Main — תוכן הסיפורים
- לכל "פרק" (chapter) יש `chapter-header` — קופסה מעוגלת (`border-radius: 20px`) עם צבע רקע ייחודי, אייקון אימוג'י גדול, כותרת בפונט Fredoka One, ותת-כותרת. יש אפקט "הילה" מעוגל שקוף ברקע (`::after` עם `radial-gradient`).
- מתחת לכל כותרת פרק — רשימת **כרטיסי סיפור** (`story-card`):
  - כרטיס לבן מרחף (`box-shadow`), עולה ומטיל צל חזק יותר ב-hover (`transform: translateY(-3px)`).
  - כותרת הכרטיס: מספר סיפור בבועה צבעונית, כותרת הסיפור, ותגית "badge" (למשל שיוך למורה/מדריך).
  - גוף הסיפור: טקסט עברי מנוקד, `line-height: 1.9`, עם כותרות משנה מודגשות בפס צבעוני מהצד (`border-right: 4px solid var(--pink)`), פסקאות מודגשות עם רקע גרדיאנט עדין, רשימות עם בולט אימוג'י (🍭) במקום נקודה רגילה, וקו מפריד גרדיאנטי (`hr.story-sep`) בין קטעים.

### 4.5 אנימציית קונפטי
- שכבת `position: fixed` ברקע כל העמוד (`z-index: 0`, `pointer-events: none`) עם אימוג'ים מרחפים (`@keyframes float` — תזוזה אנכית + סיבוב עדין, לופ אינסופי).

### 4.6 כפתור "חזרה למעלה"
- כפתור עגול צף בפינה תחתונה-שמאלית, גרדיאנט ורוד-סגול, מופיע רק אחרי גלילה מסוימת (בשליטת JS).

### 4.7 הדגשת סיפור בקפיצה (jump-to)
- לחיצה על תוצאת חיפוש/קישור בתפריט גוללת (`scrollIntoView({behavior:'smooth'})`) לכרטיס הסיפור, ומדגישה אותו זמנית באנימציית פעימה סביב הצל (`pulse-border`, פעמיים).

## 5. רספונסיביות והדפסה

```css
@media (max-width: 900px) {
  .layout { flex-direction: column; }
  .sidebar { width: 100%; height: auto; position: relative; }
  .main { padding: 1rem; }
}
@media print {
  .sidebar, .confetti, #backTop { display: none !important; }
  .story-card { break-inside: avoid; box-shadow: none; border: 1px solid #ccc; }
}
```
במסך צר — הסיידבר יורד להיות עמודה עליונה מלאה-רוחב במקום עמודה קבועה בצד.
בהדפסה — מוסתרים הסיידבר, הקונפטי וכפתור החזרה למעלה, וכל כרטיס סיפור לא נחתך בין עמודים.

## 6. מבנה הנתונים לחיפוש

בתחתית הקובץ, לפני `</body>`, מוגדר מערך JavaScript (לא JSON תקני — אובייקטים עם מפתחות ללא מרכאות, ומחרוזות במרכאות בודדות) בשם `searchData`:

```js
const searchData = [
  {id:'story-1', title:'כותרת הסיפור', body:'טקסט הסיפור המלא, כולל כל הסעיפים...'},
  {id:'story-2', title:'...', body:'...'},
  // ...
];
```

- `id` תואם למזהה ה-`<article id="...">` של כרטיס הסיפור בגוף העמוד (כדי לאפשר קפיצה ישירה).
- `title` ו-`body` הם שדות טקסט חופשי שמחפש הבחיפוש (`.includes(q)` — התאמה תת-מחרוזתית פשוטה, לא fuzzy).
- הערות תרגום/מקורות בסוגריים מרובעים (`[מקור...]`) יכולות להישאר בתוך ה-`body` כחלק מהטקסט המקורי, ולא מוצגות בפני הקורא בצורה נפרדת.
- כל תו מיוחד (`'`, `\`, שורות חדשות) מבוטח (escaped) כך שהמערך יישאר JS תקין.

## 7. תוכן עברי — כללי ניקוד וסגנון כתיבה

הסיפורים בפועל (כפי שנכתבו עד כה בקובץ) נבנים לפי תבנית קבועה, לכל סיפור:
1. **כרטיס זיהוי / בירור מקדים** — גיבור, קונפליקט, נקודת שיא, מוסר השכל.
2. **הסיפור המלא** — מחולק לפרקי משנה (א', ב', ג'...), טקסט מנוקד במלואו, עם "נקודות עצירה" מודגשות לסיפור בקול (`שורה X: "כאן — עצור..."`).
3. **חיבור ערכי ME - WE - YOU** — שלוש פסקאות שמקשרות את מוסר הסיפור לילד/ה עצמו/ה, ל"אנחנו ביום-יום", ול"אתה מחר בבוקר".
4. **מדריך למורה/למספר** — שאלת פתיחה, הערות ביצוע וסטוריטלינג (טון קול, קצב, שפת גוף), המלצות להצגה (4 שקופיות מתוארות), פעילות מסכמת (משחק תפקידים).
5. **מקורות** — רשימת מקורות תלמודיים/מדרשיים בסוף.
