# candy-pop-storybook — הקבצים המתוקנים

עותק של שלושת הקבצים ששונו בסקיל, כדי שתוכל לעדכן אותם **בחשבון שלך**.

הסקיל מסונכרן מהחשבון (`source: custom`, `skill_01F1owuCattaHoZveUnUpoH1`).
התיקון שנעשה כאן חי בסביבה הזו בלבד — סנכרון עתידי עלול לדרוס אותו, והוא
אינו חוזר לחשבון מעצמו. כדי שיישאר, יש להעלות את הקבצים האלה לסקיל בחשבון.

| קובץ | מה שונה |
|---|---|
| `scripts/validate_book.py` | ארבעה תיקונים: זיהוי שתי צורות של רשומת החיפוש; בדיקת שרשרת הקודם/הבא (קישור חסר = שבור); "חזרה לתוכן העניינים" לפי סיפור ולא ספירה גלובלית; בדיקת גודל שמדווחת gzip ומתריעה על ספר ארוך |
| `assets/book.js` | מעבר שני בחיפוש לכתיב מלא/חסר — בלעדיו ספר מנוקד אינו מוצא את כותרותיו שלו |
| `SKILL.md` | שני לקחים: החצי השני של החיפוש בספר מנוקד, וסעיף "A book that has grown long" עם המדידות ועם `content-visibility` |

הכל נבדק: שני הקטלוגים האמיתיים עוברים, בדיקות חבלה נכשלות כנדרש, הפורמט
הישן עדיין מזוהה, והבנאי `build_book.py` מייצר ספר שעובר ושחיפושו עובד.
