# torah-html-article-v2 — מה אפשר לבקש ומה קבוע

מדריך שימוש מעשי לסקיל. כל שורה כאן נגזרת מהמפרט עצמו
(`SKILL.md`, `references/editorial.md`, `references/checklist.md`), לא מהערכה.

---

## 1. מה תמיד קורה, בלי שתבקש

אלה ברירות המחדל. אתה לא צריך לבקש אותן, והן יגיעו בכל קובץ.

| מה | פרטים |
|---|---|
| **קובץ HTML יחיד ועצמאי** | בלי CDN, בלי Google Fonts, בלי תמונות מרוחקות. עובד בלי אינטרנט. גרפיקה = SVG מוטבע או אימוג'י בלבד. |
| **עברית RTL** | `<html lang="he" dir="rtl">`, גופני Segoe UI / Assistant / Noto Sans Hebrew. |
| **פלטת הבית** | סגול `#7e22ce` לכותרות פרק, כחול `#2563eb` לתת-כותרות, ירוק `#059669`, זהב `#f59e0b` לציטוטים, ורוד `#ec4899` להדגשה. |
| **סרגל הקראה קולית מלא** | חובה בסקיל. ראה סעיף 4. |
| **תוכן עניינים היררכי** | כל פרק כקישור, ומתחתיו כל תתי-הסעיפים כקישורים עצמאיים. |
| **רשת פרקים (`.chapter-grid`)** | מבט-על ממוספר של כל הפרקים בפתיחה, בנוסף לתוכן העניינים. |
| **מוכן להדפסת A4** | כולל הסתרת סרגל ההאזנה בהדפסה ומניעת חיתוך קופסאות בין עמודים. |
| **מצב כהה** | אוטומטי, דרך משתני CSS. |
| **כפתור חזרה למעלה** | |
| **חתימת סיום** | בלוק החתימה של קול תודה / הרב יהודה טאוב — מחייב, בסוף כל קובץ. |
| **פורמט גלילה רציפה** | ברירת המחדל. ספר מתחלף רק אם ביקשת. |
| **אורך "מורחב"** | ברירת המחדל היא **לא** רק לערוך את המקור, אלא להוסיף הסברים, חיבורים בין מקורות ושאלות מנחות. |
| **רשימת מקורות בסוף** | `.sources` שתואמת לכל ציטוט בגוף. |

## 2. מה אתה יכול לבקש — והסקיל יעשה

| הבקשה | מה תקבל |
|---|---|
| **"ספר מתחלף" / "עמוד-לעמוד"** | פורמט ספר דיגיטלי עם חצים, נקודות ניווט, מונה עמודים, מקלדת (←/→/Home/End) והחלקת אצבע בנייד. **רק לפי בקשה מפורשת** — אחרת תקבל גלילה רציפה. |
| **"תכין כריכה"** | קובץ A4 נפרד לגמרי מהספר, ומסירה כ**תמונה** PNG. `--dpi 300` לאיכות דפוס (2481×3509), `--dpi 150` מספיק לשיתוף במסך. |
| **"כריכה עם PDF"** | מוסיף גם PDF וקטורי — זה מה שרוצים בבית דפוס. |
| **מספר פרקים מסוים** | אם לא תציין, הוא אמור **להציע לך מתווה לפני שהוא כותב הכל**. אם הוא לא הציע — בקש. |
| **"פצל את הפרק הזה לכמה עמודים"** | בספר המתחלף. בלי בקשה הוא לא יפצל פרק — פרק ארוך מקבל גלילה פנימית בתוך העמוד. |
| **"תכין גם גרסת הדפסה לספר"** | קובץ **שני** נפרד בגלילה רציפה. הספר המתחלף הוא למסך בלבד ולא מיועד להדפסה. |
| **שם קובץ או נתיב שמירה** | אחרת: שם עברי ברור בסגנון `מאמר_[נושא]_הרב_יהודה_טאוב.html`. |
| **יותר/פחות רכיבים** | `.two-columns` להשוואת שתי דעות, `.qa-box` לקושיא ותירוץ, `.story-box` לסיפור, `.verse-box` לפסוק, `.highlight-box` לנקודת מפתח, `.section-divider` למפריד גדול. |
| **"תוסיף הקדמת פרק"** | `.highlight-box` בראש הפרק עם רקע/תולדות הרב — נפרד מ"בפרק זה". |

## 3. מה לא לבקש — יישבר או ייפסל

| הבקשה | למה |
|---|---|
| **"בלי הקראה"** | כרגע ההקראה מוגדרת **חובה** בסקיל (`template.html`: "סרגל האזנה — חובה"). זה מה שהשארנו בכוונה. אם תרצה — נהפוך את זה לאופציונלי. |
| **"תקצר את קוד ההקראה"** | `tts.js` מטפל בבאגים אמיתיים שכבר נשברו: קטיעה אחרי 15 שניות ב-Chrome, נעילת מסך בנייד, חסימת הקראה אוטומטית ב-iOS, חזרה מ-bfcache. שינוי בו שובר אותם **בשקט**. |
| **"תוסיף גופן מגוגל / תמונה מהאינטרנט"** | מפר את כלל הקובץ העצמאי. הקובץ חייב לעבוד אופליין. |
| **"תמציא סיפור/מקור שיתאים"** | הסקיל אוסר במפורש. סיפור שמוזכר במקור רק בשמו — הוא ישאל אותך או ישמיט, לא ימציא. גם שמות, ציטוטים ותאריכים אסורים בהמצאה. |
| **"תשנה את גודל הכריכה"** | 794×1123px = A4 מדויק ב-96dpi. שינוי גורם לשוליים או לחיתוך בצילום. |
| **"תדפיס את הספר המתחלף"** | הוא למסך בלבד. בקש קובץ הדפסה נפרד. |
| **"תכתוב 'השם' בטקסט"** | מיותר — ההקראה כבר מבטאת `ה'` כ"השם" לבד. כתוב `ה'` רגיל. |

## 4. ההקראה — מה היא עושה לבד

| מה | פרטים |
|---|---|
| **מנוע** | `speechSynthesis` של הדפדפן. בלי API, בלי מפתח, בלי רשת, בלי עלות. |
| **מה מוקרא** | רק גוף המאמר. תוכן העניינים, המקורות, סרגל ההאזנה והחתימה **מדולגים**. |
| **ראשי תיבות** | מורחבים בהקראה בלבד (רמב"ם, שו"ע, ז"ל, ע"א). **הטקסט על המסך לא משתנה.** |
| **שם השם** | `ה'` מוקרא "השם", כולל `לה'` / `בה'` / `וה'`. בהקשר מספרי ("פרק ה'", "יום ה'", "סימן ה'") נשאר אות. |
| **לחיצה על פסקה** | מתחילה הקראה משם. **פעיל כברירת מחדל.** כפתור "👆 לחיצה" בסרגל מכבה — והכיבוי נשמר לכל המאמרים והספרים, לא רק לקובץ הנוכחי. |
| **סימנייה** | מיקום הקריאה, המהירות והקול נשמרים ב-`localStorage`. רענון באמצע — "האזן" ממשיך מהמקום. |
| **בספר מתחלף** | מקריא את העמוד המוצג בלבד, ומדפדף לעמוד הבא לבד כשסיים. עמודים בלי תוכן מדולגים. |
| **קול נשי** | ב-Chrome/Windows יש בדרך כלל רק "Microsoft Asaf" (גברי). ב-**Edge** נחשף `Microsoft Hila Online (Natural)` — נשי ואיכותי בהרבה, והקוד בוחר בו אוטומטית. דורש אינטרנט; Asaf עובד אופליין. **אם הקול לא מוצא חן בעיניך — פתח את הקובץ ב-Edge.** |

## 5. מה כדאי לתת לו מראש

- **את כל הנוסחים והטיוטות**, לא רק את האחרון או הארוך ביותר. הוא אמור לעבור על כולם ולאתר תוכן ייחודי בכל אחד.
- **קבצי docx כמו שהם.** הוא יחלץ גם `footnotes.xml` ו-`endnotes.xml` — שם מסתתרים לרוב **רוב הסיפורים** והחומר העשיר, בעוד שגוף הטקסט הוא רק השלד.
- **מספר פרקים רצוי**, אם יש לך העדפה. אחרת הוא יציע מתווה.

**אחרי הטיוטה הראשונה** הסקיל אמור לשאול אותך במפורש: *"האם נכנסו כל הסיפורים שהיו במקורות?"* — סיפורים כלליים יותר נוטים ליפול בין הכיסאות. אם הוא לא שאל, שווה לבדוק בעצמך.

## 6. איך לוודא שרץ הסקיל הנכון

הסקיל הנכון הוא **`torah-html-article-v2`**. הישן, `torah-html-article`, הוגדר כך שיופעל רק אם תקרא לו בשם.

בדיקה מהירה על הקובץ שקיבלת — חפש בו את המחרוזת `toggleListen`:

- **נמצאה** → רץ v2. יש הקראה.
- **לא נמצאה** → רץ v1 (או ש-v2 פספס את `tts.js`).
