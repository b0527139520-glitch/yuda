# מאמר תורני ב-HTML — סגנון הבית

ספר/מאמר תורני כקובץ HTML יחיד, עצמאי לחלוטין, עם הקראה קולית מובנית.

## הכלל היחיד שאסור להפר

הקוד לא נכתב מחדש בכל פעם. קבצי ה-`assets/` הם המקור היחיד, והם נבדקו.
מעתיקים אותם כמות שהם:

| קובץ | לאן |
|---|---|
| `assets/template.html` | השלד לגלילה רציפה. ברירת המחדל. |
| `assets/base.css` | הדבק לתוך `<style>`. כללים ייחודיים למאמר — רק **אחריו**. |
| `assets/tts.js` | הדבק לתוך ה-`<script>` האחרון, **מילה במילה**. |
| `assets/template-paginated.html` | השלד לספר מתחלף (עמוד-לעמוד). |
| `assets/paginated.css` | נוסף **אחרי** `base.css`, רק בפורמט המתחלף. |
| `assets/paginated.js` | נוסף **לפני** `tts.js`, רק בפורמט המתחלף. |
| `assets/template-cover.html` | כריכת A4. קובץ נפרד לגמרי מהספר. |
| `scripts/render-cover.mjs` | הופך את הכריכה לתמונה ול-PDF. |
| `assets/audio-player.js` | נגן ההקלטה. מוטמע אוטומטית על ידי `make-audio.mjs`. |
| `scripts/make-audio.mjs` | מפיק MP3 בקול הילה ומטמיע את הנגן. |

אל תקצר את `tts.js`, אל תשכתב אותו ואל "תשפר" אותו תוך כדי. הוא מטפל בשורה של
באגים אמיתיים בדפדפנים (קטיעה אחרי 15 שניות ב-Chrome, נעילת מסך בנייד, חסימת
הקראה אוטומטית ב-iOS, חזרה מ-bfcache) שנשברים בשקט אם משנים בו משהו.

**לפני שאתה כותב תוכן, קרא את `references/editorial.md`** — כללי איסוף הסיפורים,
מבנה פרק, מעבר בין פרקים ומפתח עניינים היררכי. הם חובה, לא המלצה.
`references/checklist.md` היא רשימת האימות לפני מסירה — עבור עליה.

## תהליך

1. **תוכן גולמי / תמליל** — ארגן מחדש למבנה פרקים הגיוני, אל תשפוך לפי הסדר שהתקבל.
   תקן שגיאות תמלול מובהקות בשקט (למשל "כל תודה" ← "קול תודה").
   ייחוס מקור שאינו ודאי — שאל, אל תנחש. לעולם אל תמציא מראה מקום.
2. **נושא בלבד** — כתוב מאמר שלם ומבוסס בעצמך.
3. בנה מהתבנית והרכיבים.
4. שמור בשם עברי ברור, למשל `מאמר_[נושא]_הרב_יהודה_טאוב.html`, בתיקיית העבודה
   הנוכחית או בנתיב שהמשתמש נתן. (בסביבת הדפדפן של claude.ai:
   `/mnt/user-data/outputs/`.)
5. עבור על `references/checklist.md`.
6. מסור את הקובץ (ב-Claude Code: `SendUserFile`; בסביבת הדפדפן: `present_files`)
   עם שורת סיכום אחת. בלי נאום סיום.

## אילוצים טכניים

- קובץ HTML יחיד. שום דבר חיצוני: אין CDN, אין גופנים מרוחקים, אין תמונות מרוחקות.
  גרפיקה — רק SVG מוטבע או אימוג'י. הקובץ חייב לעבוד בלי אינטרנט.
- `<html lang="he" dir="rtl">`, גופנים: `'Segoe UI', 'Assistant', 'Noto Sans Hebrew', Arial, sans-serif`.
- רספונסיבי, מוכן להדפסת A4, ותומך במצב כהה — הכל כבר ב-`base.css`.
- לכל `<h2>` יש `id="sectionN"` ייחודי שתואם לעוגן בתוכן העניינים.
- וניל JS בלבד.
- העיצוב משרת את הטקסט. אל תעמיס עד שהוא מסיח מהתוכן.

## ההקראה — מה חשוב לדעת

`speechSynthesis` של הדפדפן בלבד: בלי API, בלי מפתח, בלי רשת, בלי עלות.

- מוקרא רק גוף המאמר. תוכן העניינים, המקורות, סרגל ההאזנה והחתימה מדולגים.
- כל פסקה נשלחת מפוצלת לאמירות של עד 180 תווים — זה מה שמונע את הקטיעה
  אחרי ~15 שניות ב-Chrome, שהייתה הורגת את ההקראה באמצע פסקה.
- ראשי תיבות מורחבים לפני ההקראה בלבד (רמב"ם, שו"ע, ז"ל, וכו'). **המסך לא משתנה.**
- **`ה'` מוקרא "השם"** ולא כאות בודדת — כולל צורות מוטות (`לה'`, `בה'`, `וה'`).
  בהקשר מספרי ("פרק ה'", "יום ה'", "סימן ה'") הוא נשאר אות, כי שם זה באמת מספר.
  כתוב `ה'` כרגיל בטקסט; אל תכתוב "השם" על המסך כדי לעקוף את זה.
- לחיצה על כל פסקה מתחילה להקריא ממנה. קישורים וסימון-להעתקה ממשיכים לעבוד.
  מי שקורא בשקט יכול לכבות את זה בכפתור **"👆 לחיצה"** שבסרגל — הכיבוי נשמר
  ונשאר בתוקף בכל המאמרים והספרים, לא רק בקובץ הנוכחי.
- מיקום הקריאה נשמר ב-`localStorage`, וכך גם המהירות והקול הנבחר.

**קול נשי:** ב-Chrome ב-Windows יש בדרך כלל רק "Microsoft Asaf" (גברי). ב-Microsoft Edge
נחשף דרך אותו API גם קול ענן נשי, `Microsoft Hila Online (Natural)`, שאיכותו גבוהה
בהרבה — הקוד בוחר אותו אוטומטית אם הוא קיים. הוא דורש אינטרנט; Asaf עובד אופליין.
אם המשתמש מתלונן על הקול, זו השאלה הראשונה: באיזה דפדפן הוא פותח את הקובץ.

## הקלטה מוכנה מראש (MP3)

בנוסף להקראה החיה של הדפדפן, אפשר לצרף לספר **הקלטה אמיתית** בקול הילה
(`he-IL-HilaNeural`) — קול ענן איכותי, בלי מפתח API ובלי עלות. זה פותר את
בעיית הקול הגברי ב-Chrome, ועובד גם במכשירים שבהם ההקראה החיה חלשה.

```bash
npm install linkedom          # פעם אחת, בתיקיית הסקיל
pip install edge-tts          # פעם אחת
node scripts/make-audio.mjs "ספר.html"
```

- **לפי בקשה בלבד.** ספר רגיל לא מקבל הקלטה אלא אם המשתמש ביקש.
- הטקסט נשאב דרך **אותה לוגיקה של `tts.js`** — אותה `SKIP` ואותה `forSpeech`.
  הסקריפט קורא אותן מקובץ המקור עצמו, ולכן ההקלטה מדלגת על תוכן העניינים,
  המקורות והחתימה, ומבטאת `ה'` כ"השם" וראשי תיבות במלואם — בדיוק כמו ההקראה
  החיה. **אל תשכפל את הכללים האלה לסקריפט.**
- ברירת המחדל: **MP3 לכל פרק** (`ספר-01.mp3`, `ספר-02.mp3`...) ונגן אחד בראש
  הקובץ עם בורר פרקים, מעבר אוטומטי לפרק הבא, והמשך מהמקום שבו עצרת.
  `--single` מייצר קובץ אחד לכל הספר.
- `--voice` להחלפת קול, `--rate +10%` למהירות, `--dry-run` לבדיקה בלי רשת.
- **ההדגשה נעה גם בהקלטה.** `edge-tts` מפיק `.srt` עם תזמון לכל מילה, הסקריפט
  ממפה אותו חזרה לפסקאות ומטמיע מפת זמנים; הנגן מדליק את אותה
  `.reading-highlight` של ההקראה החיה, גולל רק כשהפסקה מחוץ למסך, ובספר מתחלף
  גם מדפדף לעמוד הנכון. אין צורך בשום הגדרה — זה קורה מעצמו.
- הרצה חוזרת **מחליפה** את הנגן הקיים ולא מוסיפה שני. תזמונים קיימים נשמרים,
  כך שאפשר להריץ שוב על פרק בודד בלי לאבד את השאר.
- הקבצים נשמרים ב-`audio/` ליד ה-HTML. **הקובץ כבר לא עצמאי** — צריך להעביר
  את התיקייה יחד איתו. בלעדיה הנגן פשוט לא ינגן; שאר הדף עובד כרגיל.
- **שורת הורדה + בחירה ידנית, תמיד.** בנגן יש קישור "📥 להורדת קובץ השמיעה
  לחץ כאן" וכפתור "📂 בחר את הקובץ שהורדת". `--download-url "https://..."`
  ממלא את הקישור; בלעדיו נשתל `href="#"` עם `data-download-placeholder`
  שאפשר לחפש ולערוך ביד, והקישור **מוסתר מהקורא** עד שממלאים אותו.
  דפדפן לא יכול לקרוא את תיקיית ההורדות בעצמו — לכן הבחירה הידנית היא
  המנגנון, והיא עובדת אופליין ובכל דפדפן. אפשר לבחור את כל פרקי הספר בבת אחת;
  ההתאמה לפי שם הקובץ. **ההדגשה עובדת גם כך**, כי התזמונים כבר בדף.
  שים לב: קישור שיתוף רגיל של דרייב (`/file/d/ID/view`) הוא דף צפייה ולא קובץ —
  הוא מצוין כקישור הורדה, אבל לא ינגן ישירות ב-`<audio>`.
- ה-`.txt` שנשמר לצד כל MP3 הוא הטקסט שהוקרא בפועל — שימושי לבדיקה.

## כריכה

לכל ספר מכינים כריכה — `assets/template-cover.html`, קובץ נפרד לגמרי מהספר עצמו.
מלא את ה-`{{...}}` ואז **מסור אותה כתמונה**, לא כ-HTML: תמונה אפשר לשלוח בוואטסאפ,
לשלוח לדפוס, ולהשתמש בה כתמונה ממוזערת.

```bash
node scripts/render-cover.mjs "כריכה_שם_הספר.html" --dpi 300 --pdf
```

- משתמש ב-Chrome או Edge שכבר מותקנים. **אין מה להתקין.**
- `--dpi 300` → 2481×3509 px, איכות דפוס. `--dpi 150` מספיק לשיתוף במסך.
- `--pdf` מוסיף גם PDF וקטורי — עדיף לבית דפוס.
- מסור למשתמש את ה-PNG (ואת ה-PDF אם הופק). את ה-HTML שמור לצד הספר לעריכות עתידיות.

הקנבס בתבנית הוא בדיוק A4 ב-96dpi (794×1123px), ולכן הצילום יוצא מדויק בלי שוליים
ובלי חיתוך. אל תשנה את המידות האלה.

## כללי כתיבה

הכללים המלאים — איסוף סיפורים, מבנה פרק, כריכה, עומק — ב-`references/editorial.md`.
התמצית:

- אל תמלא בסתם. כל קופסה צריכה להצדיק את עצמה — פסוק אמיתי, מחלוקת אמיתית, מעשה אמיתי.
- כל הסיפורים מכל המקורות, **כולל מהערות שוליים והערות סיום** — שם מסתתר לרוב
  החומר העשיר ביותר. סיפור שהוזכר רק בשמו — אסור להמציא את תוכנו.
- אורך יעד: **מורחב**. להוסיף הסברים, חיבורים בין מקורות ושאלות מנחות, לא רק לערוך.
- כששני מפרשים קוראים את אותו כתוב בשתי דרכים (למשל ביטוי שאחד מבין כשכר והשני
  כגזירה) — הצג את המתח במפורש, בדרך כלל ב-`.two-columns`. זה מה שהופך מאמר
  למעניין, לא הקישוט.
- דייק בייחוס. מקור שלא ניתן לאמת — השמט או סמן, אל תמציא.
- סיים תמיד ב-`.sources` שתואם לכל ציטוט שבגוף.

### פסק לאוזן, לא רק לעין

כל מאמר נצרך גם בהאזנה, ומנועי הקראה מתזמנים את עצמם לפי סימני פיסוק בלבד:

- סיים כל משפט בנקודה. פסיק בכל נקודת נשימה טבעית.
- עטוף פסוקים וציטוטי חז"ל במירכאות, עם פיסוק לפני ואחרי.
- פרק משפטים ארוכים משורשרים ב"ו" למשפטים קצרים. אחרת הם נקראים בנשימה אחת.
- מילה שבלי ניקוד משמעותה מתהפכת (שָלוֹם מול שָלֵם) — נקד את המילה הזו בלבד,
  לא את המאמר.

## פורמט תצוגה

**גלילה רציפה** (ברירת מחדל) — `template.html` + `base.css` + `tts.js`.
מתאים גם להדפסה. מעבר בין פרקים נעשה ב-`.chapter-card` + `.chapter-divider`.

**ספר דיגיטלי מתחלף** — רק כשהמשתמש ביקש במפורש.
`template-paginated.html` + `base.css` + `paginated.css` + `paginated.js` + `tts.js`.

- כל פרק הוא `<div class="page">` בתוך `<div class="container" id="book">`.
  עמוד ראשון = כריכה פנימית, שני = מפתח עניינים, אחרון = חתימה.
- פרק ארוך מדי למסך — גלילה פנימית בתוך העמוד (כבר ב-CSS). **אל תפצל פרק
  אחד לכמה עמודים בלי שהמשתמש ביקש.**
- `paginated.js` נותן חצים, נקודות ניווט, מונה עמודים, מקלדת (←/→/Home/End)
  והחלקת אצבע. מפתח העניינים משתמש ב-`data-page="3"` במקום עוגנים.
- סרגל ההאזנה צף מעל הניווט, מקריא את **העמוד המוצג בלבד**, ומדפדף לעמוד הבא
  מעצמו כשסיים. עמודים בלי תוכן להקראה מדולגים. הכל אוטומטי — אל תוסיף קוד.
- **גובה הפקדים נמדד בזמן ריצה** (`--chrome-h`) ולא מקובע ב-CSS. הסרגל גדל
  כששם הקול ארוך וכשהוא נשבר לשתי שורות בנייד; מספר קשיח שם פירושו סרגל
  שמכסה את סוף הטקסט. אל תחליף את המדידה בערך קבוע.
- כפתור ⌄ מקפל את הסרגל לגלולה צפה בפינה. מקופל הוא לא גוזל גובה כלל —
  שטח הקריאה גדל מ-74% ל-87% מהמסך. הבחירה נשמרת ב-localStorage.
- הפורמט הזה הוא **למסך בלבד**. אם רוצים גם גרסת הדפסה של הספר — הכן קובץ
  שני נפרד בגלילה רציפה. אל תנסה להדפיס את המתחלף כמות שהוא.
